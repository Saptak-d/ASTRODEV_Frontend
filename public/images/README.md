# Images Directory

Place your static website images (PNG, JPG, SVG, WebP) in this folder.

### How to use them in React components:
Any image placed here (for example `banner.jpg`) can be used directly with the URL `/images/banner.jpg`:

```jsx
<img src="/images/banner.jpg" alt="Astrology Banner" className="w-full h-auto rounded-xl" />
```

Or as a CSS background:
```css
background-image: url('/images/banner.jpg');
```
